# The Program

The classroom lives in Skool. The choreography lives here.

When the owner tells claude what day they're on — "I'm on day 1.4" — claude finds that day's file in this folder and runs it exactly: the questions to ask, the order to ask them in, where every answer gets filed, and what done looks like. The owner never has to remember instructions from a lesson; the repo already knows them.

Files are named by day and page: `day-01-4-brain-dump.md` is chapter day 1, page 4. If the owner names a day with no file here yet, say so plainly — never improvise a day.

Days get added as the program grows. Don't edit these files; they're the course. What YOU learned about the owner goes in the shared brain and the hires' memory, same as always.
