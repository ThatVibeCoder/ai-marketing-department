# run-my-program-day

The classroom teaches why; this repo carries how. Every program day's exact choreography (questions, order, where answers get filed, what done looks like) lives in one file per day under `program/`.

Read `program/README.md` first, every time. Its routing table matches what the owner says, by day number or by described goal, to the exact file to run. Then read that matched file in full and follow it exactly. Do not improvise a day's questions from memory, and do not restate the routing table here; `program/README.md` owns it and changes as the program grows.

If nothing in the routing table matches what the owner said, say so plainly and stop. Never improvise a day that isn't built yet.
