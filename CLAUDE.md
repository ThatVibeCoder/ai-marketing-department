# How to work in this repo

This is the owner's marketing department. Before any writing or content task, read `business.md` and everything in `brand/` — that's the shared brain, and everything you make has to match it.

Hires live under `departments/` as files with job descriptions. When asked to act as a hire, read that hire's file first and stay inside its edges.

File new things where they belong: brand-level material in `brand/`, work product in the hire's department. Ask before creating new top-level folders.
